# Cássio Pescador · prévia

Prévia do site de **Cássio Pescador** (@tattoocassio), realismo preto e cinza em Concórdia (SC). Site por L R G Z.

- Hero "salão de retratos": moldura dourada barroca na parede adamascada preta (como no estúdio dele); dentro dela a peça se forma do preto ao cinza (`js/retrato.js`, WebGL). No celular em pé, `img/hero/retrato.mp4` (gerado por `../tools/gravar.py`).
- Portfólio: 64 peças em `js/pecas.js` (filtros Retratos, Feras, Fé e mitologia, Fechamentos).
- Formulário `#form` → wa.me/5549998030915.
